# CS2 Voice Control

Голосовое управление для Counter-Strike 2! CS2 Voice Control позволяет управлять передвижением, камерой, стрельбой и закупом без использования клавиатуры и мыши.
## Требования
* Windows 10 / 11
* Микрофон
* Counter-Strike 2

## Установка и запуск

### Вариант 1: Готовая сборка (без установки Python)
1. Перейдите в раздел **[Releases](../../releases)** и скачайте архив **`CS2_Voice_Control_v1.0.zip`**.
2. Распакуйте архив в любую папку.
3. Запустите **`CS2_Voice_Control.exe`** от имени администратора.
4. Введите вашу чувствительность мыши из CS2 и нажмите enter.
5. Переключитесь в окно игры (рекомендуется режим «Полноэкранный в окне»).

### Вариант 2: Запуск из исходного кода (для разработчиков)
1. Установите [Python 3.10+](https://python.org).
2. Скачайте репозиторий (**Code -> Download ZIP**) и запустите **`START.bat`** — скрипт сам установит зависимости и скачает языковую модель.



## Список голосовых команд

### Передвижение
* **«Прямо»** — бег вперёд до команды остановки.
* **«Прямо [время]»** — бег вперёд на заданное время (`четверть`, `полсекунды`, `один`..`десять`, `пятнадцать`, `двадцать`, `тридцать`).
* **«Назад» / «Лево» / «Право»** — шаг в соответствующую сторону.
* **«Прыжок»** — прыжок на месте.
* **«Прыжок прямо»** — прыжок с разбега и поджатием ног (для запрыгивания на препятствия).
* **«Ползи»** — режим приседа (отмена: **«Встань»** или **«Стой»**). Поддерживает таймер: **«Ползи [1..10]»**.
* **«Тихо»** — шаг без шума (отмена: **«Бегом»** или **«Стой»**).
* **«Стой»** — полная остановка движения, камеры, приседа и шага.

### Управление камерой
* **«Налево [градусы]» / «Направо [градусы]»** — поворот камеры на указанный угол (например: *«налево пятнадцать»*, *«направо сорок пять»*, *«налево девяносто»*). Без указания числа — поворот на 45°.
* **«Вверх [градусы]» / «Вниз [градусы]»** — вертикальный сдвиг прицела (без указания числа — на 15°).
* **«Разворот»** — разворот на 180°.
* **«Веди лево» / «Веди право»** — плавное непрерывное ведение прицела до команды **«Стой»**.
* **«Веди быстро лево» / «Веди быстро право»** — ускоренное ведение прицела.

### Стрельба и действия
* **«Огонь»** — одиночный выстрел.
* **«Очередь»** — короткая очередь (3–4 выстрела).
* **«Стреляй [число]»** — серия из указанного количества выстрелов (от 8 и выше — непрерывный зажим).
* **«Прицел»** — активация оптического прицела / альтернативного режима огня.
* **«Перезарядка»** (или **«Обойма»**) — перезарядка оружия.
* **«Сброс»** — выбросить текущее оружие.

### Слоты снаряжения
* **«Винтовка»** — основное оружие (`1`)
* **«Пистолет»** — пистолет (`2`)
* **«Нож»** — нож (`3`)
* **«Зевс»** — Zeus x27
* **«Бомба»** — C4 (`5`)
* **«Граната»** — осколочная граната (`6`)
* **«Флешка»** — световая граната (`7`)
* **«Дым»** — дымовая граната (`8`)
* **«Молотов»** — зажигательная граната / коктейль Молотова (`0`)

### Голосовой закуп
1. **«Закуп»** — открыть меню покупки.
2. **«Купить [столбец 1..5] [слот 1..5]»** (или **«Столб [1..5] слот [1..5]»**) — покупка предмета по координатам сетки меню (например: *«купить четыре два»*).
3. **«Закрыть»** (или **«Закуп»**) — закрыть меню покупки.
